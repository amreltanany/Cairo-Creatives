# Cairo Creatives

Agency website for Cairo Creatives, built with [Astro](https://astro.build).

Live: https://amreltanany.github.io/Cairo-Creatives/

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:4321/Cairo-Creatives/

## Deploy

Every push to `main` builds the site and publishes it to GitHub Pages (`.github/workflows/deploy.yml`).
